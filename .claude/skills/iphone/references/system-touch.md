# Пальцы: внутри LiteBro и по всей системе

Прочитай целиком, прежде чем перебирать варианты: большая часть уже перебрана.

## Что есть сейчас

| Что | Состояние |
|---|---|
| Открыть адрес, JavaScript страницы, контролы LiteBro, текст (`open`, `js`, `click`, `type`) | Работают без пальцев: приложение само делает то, о чём просят. Основной путь |
| Кнопки «Домой» и боковая (`button`) | Проходят по всей системе: проверено на телефоне 2026-11-26 |
| Палец внутри LiteBro (`tap`, `swipe`, `hold`: `"inApp": true`, очередь событий самого приложения, как в UI-тестах Apple) | На телефоне 2026-11-27 событие создаётся и ставится в очередь (ответ: окно есть, `enqueue` true, под пальцем нужный вид), но нажатия не происходит. С масками WebKit (`--opt recipe=trollvnc`) не пробовали |
| Палец по всей системе (`--system`) | Не проходил ни в одном из перебранных вариантов. Вариант «как TrollVNC» (`recipe=trollvnc`, помощник шлёт его сам) на телефоне ещё не проверен |
| Управлять другим приложением | Даже с рабочим пальцем мало: LiteBro в фоне заморожен и запросы не принимает. См. «Другие приложения» |

## Что перепробовано на телефоне (iPhone, iOS 16.2, 2026-11-26 и 27, PR 78, 81, 82, 84, 85)

- Из расширения экрана (`POST …:8081/<секрет>/touch`): не доходят ни касание, ни «Домой». Песочница расширения не пускает к системе событий HID, даже с правами в подписи.
- Из приложения по всей системе (`POST …/_touch`): «Домой» доходит, палец — нет. Перебраны клиенты `plain`, `simple`, `admin`; отправители `0x000000010000027F` и `0x8000000817319372`; с `BKSHIDEventSetDigitizerInfo` и без; координаты 0…1 и точки; разные `index`; касание и протяжка.
- Из приложения в своё окно (`"inApp": true`): ответ телефона говорит, что окно ключевое, событие принято в очередь и под точкой нужный вид, а на экране ничего не меняется.
- Оговорка: результат тогда смотрели по картинкам сборки без `…/frame`, а она новому зрителю первой отдаёт картинку прошлого просмотра. Часть «не сработало» могла быть ошибкой наблюдения. Перепроверяй на сборке с `frame` и всегда с `--shot`.

## Рецепт из открытого кода: TrollVNC

TrollVNC (`OwnGoalStudio/TrollVNC`, GPL-2.0) — сервер VNC для телефонов с TrollStore, нажимает по всей системе без джейлбрейка и работает от пользователя `mobile`, как LiteBro. Его генератор событий (`src/STHIDEventGenerator.mm`) происходит от `HIDEventGenerator` из WebKit. Параметры ниже сняты двумя независимыми чтениями исходника 2026-11-27 (код не копировался); на этом телефоне рецепт не проверен.

LiteBro собирает касание так только по ключу запроса `"recipe": "trollvnc"`; без ключа всё как раньше. Помощник ставит ключ сам у `--system`; для пальца внутри LiteBro его надо назвать: `--opt recipe=trollvnc`.

| | TrollVNC | LiteBro без ключа | LiteBro с `recipe=trollvnc` |
|---|---|---|---|
| Клиент | `IOHIDEventSystemClientCreate` | он же (`client=plain`) | он же |
| Отправитель события | `0x8000000817319371` | `…027F`; пробовали и `…372` | `…371` |
| Маска события: начало и конец касания | touch + identity | range + touch (+ position в начале) | touch + identity (`masks=webkit`) |
| Маска: движение | position + attribute | position | position + attribute |
| Координаты пальца | доли 0…1 | доли 0…1 | доли 0…1 |
| Точка в событии «рука» (по всей системе; внутри LiteBro она всегда 0 и 0, `parentXY` там не действует) | нет, 0 и 0 | есть | нет (`parentXY=false`) |
| Палец: `index` и `identity` | 2 и 2 | 1 и 2 | 2 и 2 |
| Давление, поворот, радиус пятна | 0, 90, 5 | 1, 0, не задан | 0, 90, 5 (`pressure`, `twist`, `radius`) |
| `BKSHIDEventSetDigitizerInfo` | не вызывается | вызывается | по всей системе не вызывается (`bks=false`); внутри LiteBro вызывается: он несёт окно |
| Поля «встроенный» и «экран в дисплее» на событии «рука» (внутри LiteBro ставится только «экран в дисплее», `builtIn` там не действует) | ставятся | ставятся | ставятся |
| Права в подписи сверх наших | `…hid.client.event-filter`, `…event-monitor`, `com.apple.backboard.client`, список `com.apple.security.iokit-user-client-class` | — | добавлены в `ios/TrollStore.entitlements` |

Любой ключ рецепта меняется опцией: `--opt masks=plain`, `--opt sender=0x000000010000027F`, `--opt bks=true`, `--opt index=1` и так далее. `--opt recipe=none` у `--system` — собрать как раньше.

## Как проверять на телефоне

1. Убедись, что на телефоне сборка с рецептом и с `…/frame`: `iphone touch` печатает отчёт с `"recipes":["trollvnc"]`, а `iphone shot` отвечает `live`. Нет — обнови LiteBro (`iphone install`).
2. LiteBro на экране, показ экрана идёт. Выбери место, где касание заметно, — поле адреса на стартовой странице. Сначала палец внутри LiteBro, как есть и как WebKit:
   ```bash
   iphone tap 0.4 0.93 --shot
   iphone tap 0.4 0.93 --opt recipe=trollvnc --shot
   ```
   `changed=yes` и клавиатура на картинке — палец работает.
3. Потом по всей системе:
   ```bash
   iphone tap 0.4 0.93 --system --shot
   ```
4. Не сработало — меняй по одной опции за раз, каждый раз с `--shot`: `--opt sender=0x8000000817319372`, `--opt masks=plain`, `--opt index=1`, `--opt radius=0`, `--opt pressure=1`, `--opt bks=true`, `--opt client=simple`. Не перебирай всё со всем: шесть-семь проб, не сотня.
5. Результат (что сработало, что нет, какая сборка, дата) допиши в этот файл. Без записи следующая сессия пройдёт тот же путь заново.

## Другие приложения

Когда палец по всей системе заработает, останется второе препятствие: стоит открыть другое приложение, и iOS через пару секунд замораживает LiteBro вместе с его сервером. Что может это снять (ничего из этого ещё не сделано):

- LiteBro, пока открыт доступ, держит себя живым в фоне тихим звуком: режим фонового звука у приложения уже объявлен (`UIBackgroundModes: audio` в `ios/project.yml`).
- Отдельный процесс-помощник, который приложение запускает и который живёт сам (так устроен TrollVNC).

## Готовые варианты вне LiteBro

Не подключены и на этом телефоне не проверены. Предлагай пользователю, когда задача упирается в чужие приложения; ставить на телефон что-либо — только с его согласия.

| Вариант | Что даёт | Чего стоит |
|---|---|---|
| **TrollVNC** | экран, палец и клавиши по всей системе по VNC (порт 5901 по умолчанию; есть веб-клиент по отдельной опции), пароль | одно приложение через TrollStore; с компьютера — любой клиент VNC, из скрипта — например `vncdotool` |
| **XXTouch Elite** (версия для TrollStore) | HTTP на порту 46952: снимок экрана, запуск сценариев Lua (`touch.tap`, `app.run`) | платное; нужны сценарии |
| **WebDriverAgent**, поставленный через TrollStore, + `go-ios` или `pymobiledevice3` | полная автоматизация интерфейса (порт 8100): касания, дерево элементов, запуск приложений | кабель, «Режим разработчика» на телефоне, образ разработчика |
| **`pymobiledevice3`** по кабелю | без касаний: снимок экрана, запуск и остановка приложений, живой системный журнал, отчёты о падениях, файлы | Python на компьютере, драйвер Apple; для снимка и запуска — «Режим разработчика» и образ разработчика |
