# LiteBro

![LiteBro: плитки проектов, консоль, терминал, поиск по странам и журнал сети](docs/preview.gif)

Лёгкий браузер для локальных проектов под Windows. Внутри — движок Edge WebView2, который уже есть в Windows. LiteBro занимает меньше памяти и процессора, чем Chrome: ресурсы остаются программам, например языковой модели на CPU.

LiteBro создан для локальных адресов: `localhost`, `*.localhost`, имена из `hosts` и частные сети. Интернет в нём тоже работает, а одна кнопка на стартовой странице закрывает выход в сеть: остаются этот компьютер, локальная сеть и сайты, которые вы разрешили. Каждую попытку страницы выйти в интернет браузер записывает в журнал сети: куда, с какой страницы и чем она закончилась. Без блокировки журнал тоже можно включить.

Если LiteBro выбран для ссылок из других программ, локальные адреса он открывает сам, а остальные сразу передаёт основному браузеру (обычно Chrome), не открывая своего окна.

## Возможности

### Проекты

- **Плитки проектов.** Проект — это адрес, программа, которая его поднимает, её аргументы и папка. Клик по плитке открывает проект в этой вкладке, Ctrl+клик или колёсико — в новой. Если адрес не отвечает, LiteBro запускает программу без окна, ждёт и открывает страницу; если программа печатает адрес со входным токеном, можно открывать его. Зелёная точка на плитке значит, что программа работает, клик по ней останавливает программу. Программы закрываются вместе с LiteBro.
- **Вид плитки.** Значок сайта, своя картинка или буквы на цветном фоне. Правый клик по плитке открывает её настройки, плитки можно перетаскивать зажатием.
- **Ссылки проекта.** У плитки может быть до 20 дополнительных адресов (например, документация бэкенда). Счётчик на плитке открывает меню: сам проект, любая ссылка или «Открыть всё» — проект в этой вкладке, ссылки в фоновых.
- **Профиль проекта.** Галочка «Отдельный профиль» даёт проекту свои cookies, хранилище и разрешения. Вкладка сама переходит в профиль проекта, когда открывает его сайт; вход через чужой сайт (OAuth) остаётся в текущем профиле.
- **Избранное.** Звёздочка в адресной строке сохраняет страницу новой плиткой (с программой и папкой исходного проекта) или ссылкой в существующий проект. Золотая звёздочка значит, что адрес уже сохранён.
- **Обновление при изменении файлов.** Пока страница проекта на экране, LiteBro следит за его папкой и перезагружает страницу после сохранения файлов (node_modules, .git, bin, obj и логи не считаются). Включается на странице журнала сети.

### Консоль и терминал

- **Консоль проекта** (`>_` на плитке). Живой вывод программы и строка ввода в двух режимах. «Команда» выполняет команду в папке проекта; папку перед строкой можно исправить прямо в поле, а долгую команду — прервать. «Программе» отправляет текст программе на ввод.
- **Терминал во вкладке.** Настоящий PowerShell в псевдоконсоли Windows, рисует xterm.js. В нём работают claude, vim и другие полноэкранные программы. Открывается фиолетовой кнопкой на стартовой странице (в папке пользователя) и кнопкой «Терминал» в консоли проекта (в папке проекта). Ctrl+C с выделением копирует, Ctrl+V и правый клик вставляют; Ctrl+L, Ctrl+R, F5 и Alt+стрелки уходят оболочке. Закрытие вкладки завершает оболочку и всё, что в ней запущено.
- **Терминал плиткой.** Звёздочка сохраняет терминал плиткой: клик открывает его в той же папке и сразу запускает ту же команду, например `claude`. Если команда — программа `.exe`, плитка берёт её значок.
- **Консоль PowerShell без проекта.** Одна постоянная оболочка: переменные и модули живут между командами.

### Сеть и защита

- **Режим «только localhost».** Зелёная кнопка на стартовой странице закрывает весь выход в интернет. Остаются этот компьютер, локальная сеть, имена из `hosts` и сайты, которые вы разрешили (`*.example.com` — сайт и поддомены). Запросы перекрывает и фильтр движка, и свой шлюз на этом компьютере, поэтому не проходят ни веб-сокеты, ни запросы воркеров и самого движка; WebRTC не раскрывает адреса. HTTPS шлюз не расшифровывает. Включение и выключение перезапускает движок, программы проектов продолжают работать.
- **Журнал сети.** Каждый запрос наружу: куда, с какой страницы, кто инициатор (fetch, XHR, веб-сокет, со стеком вызовов), IP-адрес, размер и чем закончился. Сортировка по колонкам, фильтры как в Excel, выгрузка в JSON или CSV. Без блокировки журнал тоже можно включить. Журнал хранится в `logs\network.log`.
- **Игнорировать CORS.** Только вместе с режимом «только localhost»: для локальной разработки, когда фронтенд и бэкенд на разных портах.
- **Заглушки.** Подставной ответ на любой адрес: метод, адрес с `*`, код, тип и тело; ответ на предварительный запрос CORS браузер даёт сам. Заглушку можно сделать из строки журнала сети: браузер один раз возьмёт настоящий ответ сервера.
- **Блокировка рекламы.** uBlock Origin Lite убирает рекламу, трекеры и вредоносные сайты. Фильтры применяет сам движок, поэтому блокировщик почти не тратит память и процессор. Включается на странице «Для разработчика»: при первом включении LiteBro один раз скачивает его с GitHub (около 12 МБ) и сверяет файлы с выпуском. Там же кнопка его настроек; сайт без блокировки — «Не блокировать (uBlock)» в меню «Инструменты».
- **Защита от трекеров.** Обычная, как в Edge, или строгая (переключатель на странице «Для разработчика»).
- **Разрешения сайтов.** Маленькое окно из меню «Инструменты»: камера, микрофон, место, уведомления и прочее для сайта вкладки или сразу для всех сайтов и профилей. Выбор: «Разрешено», «Запрещено», «Спрашивать».
- **Сертификаты localhost.** Ошибки сертификата у `localhost`, `*.localhost` и `127.0.0.1` можно пропускать, как `--allow-insecure-localhost` у Chrome (по умолчанию выключено). У остальных сайтов браузер их показывает.
- **Очистка при выходе.** Cookies и кэш всех профилей удаляются, когда закрывается последнее окно. У проекта с галочкой «Не удалять cookies и кэш при выходе» они остаются.
- **Страницы браузера защищены.** Плитки, консоли, журнал и терминал принимают команды только от своих страниц, а вывод программ и журнал не отдаются сайтам.
- **Без телеметрии.** Фоновые запросы движка, отчёты о сбоях и SmartScreen выключены.

### Вкладки

- **Порядок.** Новая вкладка встаёт рядом с той, из которой открыта; Ctrl+T, «+» и ссылки из других программ — в конец.
- **Меню вкладки** (правый клик): «Перезагрузить», «Дублировать» (с историей назад и вперёд), «Закрепить», «Поделиться» (ссылка, ссылка Markdown, письмо), «Открыть рядом», синхронная прокрутка и звук.
- **Закреплённые вкладки** стоят в начале полосы квадратиком со значком сайта и открываются снова при следующем запуске.
- **Меню полосы вкладок** (правый клик по пустому месту или «+»): открыть закрытую вкладку (до 25, на её прежнее место и с историей), сохранить все вкладки одной плиткой с датой, диспетчер задач, закрыть все вкладки (закреплённые, терминалы с работающей оболочкой и программы проектов остаются).
- **Две вкладки рядом.** Граница между ними перетаскивается, прокрутку можно синхронизировать.
- **Звук вкладки.** Значок динамика на вкладке выключает и включает звук. Включается на странице «Для разработчика».
- **Полный экран страницы.** Видео и страницы, которые просят полный экран, занимают весь монитор без панели и вкладок; выход — Esc или F11.
- **Полоса вкладок** скрыта, пока открыта только стартовая страница.

### Память

- **Заморозка вкладок.** Фоновая вкладка через несколько секунд отдаёт лишнюю память, через минуту замораживается, через пять минут выгружается; сроки меняются на странице «Для разработчика». Вкладки со звуком, на сайте работающего проекта, терминал и вкладка с открытым хранилищем не трогаются. Выгруженная вкладка загружается снова по клику и не запускает программу проекта.
- **Память на панели.** Кнопка показывает, сколько памяти занимает браузер, как в диспетчере задач Windows; клик открывает диспетчер процессов (Shift+Esc).

### Инструменты разработчика

Кнопка «Инструменты» с гаечным ключом в адресной строке. После установки инструменты выключены и включаются на странице «Для разработчика».

- **Эмуляция устройства:** iPhone SE, iPhone 15, Pixel 7, iPad, ноутбук 1366×768, Full HD — размер экрана, касания и user agent, как режим устройства в DevTools.
- **Эмуляция сети:** быстрая и медленная 3G, офлайн.
- **Снимок страницы** целиком (до 16384 px, в том числе чатов с прокруткой внутри) или только видимой части, в PNG (Ctrl+Shift+S).
- **Хранилище сайта:** cookies, localStorage, sessionStorage и IndexedDB — смотреть, добавлять, править и очищать, создавать хранилища IndexedDB.
- **Просмотр JSON:** дерево со сворачиванием, текст, текст с отступами, копирование.
- **Сброс сайта** (кнопка с ластиком, Ctrl+Shift+R, Ctrl+F5): service worker, Cache Storage и HTTP-кэш, затем загрузка без кэша. Cookies и хранилище остаются.
- **Сохранить как** (Ctrl+S): кроме HTML и MHTML ещё PDF, картинка всей страницы, текст, таблицы страницы в CSV для Excel или JSON. У страницы JSON — сам файл и список из него в CSV.
- **Правый клик по странице → «Другие инструменты»:** снимок, сброс кэша сайта, хранилище, эмуляция устройства и сети, а при включённой блокировке рекламы — «Не блокировать (uBlock)». Они есть там всегда, даже когда их кнопки выключены.
- **Страна поиска.** На странице поиска Google справа в адресной строке появляется кнопка выбора страны: результаты как у пользователя из этой страны (параметры `gl` и `hl`, без прокси и VPN).
- **DevTools** (F12) — обычные, от движка.

### Страница «Для разработчика»

Здесь включаются и выключаются кнопки панели, кнопки стартовой страницы и инструменты (выключенный инструмент пропадает вместе с меню и клавишами). Там же язык, тема (тёмная по умолчанию, светлая или как в Windows), видеокарта для движка, сроки заморозки вкладок, звук вкладок, защита от трекеров, сертификаты localhost и блокировка рекламы. Кнопка «Настройки по умолчанию» возвращает всё как после установки (старый `settings.ini` сохраняется в `.bak`).

### Прочее

- **Один процесс.** Ссылка из другой программы попадает в уже открытый LiteBro, вкладка на том же сайте используется снова. Chrome и другие браузеры на Chromium LiteBro запускает так, чтобы они не просили сделать их браузером по умолчанию.
- **Своя страница «Сайт не отвечает»** вместо страницы Edge, когда сервер выключен или имя не найдено; F5 или ссылка на ней пробуют снова. Пока ждёте — мини-игра (выбор справа вверху): раннер-штекер, змейка, летающий пакет, понг, арканоид, космические захватчики, сапёр и карточные — косынка, паук и свободная ячейка; рекорды запоминаются.
- **Тёмная тема** без белой вспышки при запуске, с тёмным заголовком окна.
- **Русский и английский интерфейс.** По умолчанию — как язык Windows, переключается на странице «Для разработчика».
- **Быстрые команды.** Кнопка на странице журнала сети показывает все горячие клавиши и приёмы.

## Установка

1. Скачайте `LiteBro-Setup.exe` из [Releases](https://github.com/ronanime-arch/LiteBro/releases) (справа на странице репозитория) или соберите его сами (см. «Сборка») и запустите. Нужны права администратора: программа ставится в `Program Files\LiteBro`. Установщик не подписан, поэтому Windows может предупредить о нём: «Подробнее» → «Выполнить в любом случае».
2. На шаге «Приложения по умолчанию» выберите LiteBro для HTTP и HTTPS. Windows не разрешает программам делать это самим. Внешние ссылки всё равно откроются в вашем основном браузере.

Установка и переустановка закрывают LiteBro, а вместе с ним и запущенные программы проектов.

Если стоял LiteBrowser (так браузер назывался до 1.9.7), установщик удаляет его, переносит закреп на панели задач и снова проводит через шаг «Приложения по умолчанию». Плитки, значки, журналы и входы на сайты браузер при первом запуске переносит из `%LOCALAPPDATA%\LiteBrowser` сам.

Данные хранятся в `%LOCALAPPDATA%\LiteBro`: `settings.ini`, `projects.json` (плитки), `mocks.json` (заглушки), `pinned.txt` (закреплённые вкладки), профиль WebView2, значки, `logs\` (вывод программ проектов и журнал сети) и `ublock\`. Все настройки можно вернуть без переустановки кнопкой «Настройки по умолчанию» на странице «Для разработчика».

## Сборка

Нужны Windows, .NET SDK и git. Проект на C# WinForms под .NET Framework 4.8.

```powershell
git clone https://github.com/ronanime-arch/LiteBro
cd LiteBro
.\build.ps1        # → dist\LiteBro-Setup.exe
```

Номер версии скрипт берёт из истории git (1.9.x), поэтому собирать нужно из клона репозитория.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+T, Ctrl+N | Новая вкладка, новое окно |
| Ctrl+W | Закрыть вкладку |
| Ctrl+Shift+T | Открыть закрытую вкладку |
| Ctrl+Tab, Ctrl+Shift+Tab | Следующая, предыдущая вкладка |
| Клик / Ctrl+клик или колёсико | Открыть в этой вкладке / в новой |
| F5, Ctrl+R | Обновить |
| Ctrl+Shift+R, Ctrl+F5 | Сбросить кэш сайта и загрузить заново |
| Alt+←, Alt+→, Alt+Home | Назад, вперёд, плитки |
| Ctrl+L, Alt+D, F6 | Адресная строка |
| Ctrl+F, Ctrl+P | Поиск на странице, печать |
| Ctrl+Плюс, Ctrl+Минус, Ctrl+0 | Масштаб |
| Ctrl+S | Сохранить как (HTML, PDF, PNG, текст, CSV, JSON) |
| Ctrl+Shift+S | Снимок страницы целиком |
| F12, Shift+Esc | DevTools, диспетчер процессов |
| Esc, F11 | Выйти из полного экрана страницы |
| Правый клик по вкладке | Перезагрузить, дублировать, закрепить, поделиться, открыть рядом, звук |
| Правый клик по полосе вкладок | Открыть закрытую вкладку, все вкладки — одной плиткой, диспетчер задач, закрыть все вкладки |

Полный список есть в журнале сети, кнопка «Быстрые команды».

## Лицензия

xterm.js и addon-fit встроены в программу по лицензии MIT.

uBlock Origin Lite (Raymond Hill и участники, GPLv3) в LiteBro не входит: при включении браузер скачивает его официальный выпуск из [uBlockOrigin/uBOL-home](https://github.com/uBlockOrigin/uBOL-home) и сверяет файлы с выпуском. Исходный код — там же и в [gorhill/uBlock](https://github.com/gorhill/uBlock).
