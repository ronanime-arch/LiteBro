# LiteBro для iOS

Версия LiteBro для iPhone и iPad на iOS 16, ставится через **TrollStore** (без App Store, без перевыпуска раз в 7 дней). Движок — WebKit (`WKWebView`): на iOS другого движка у браузеров нет, поэтому WebView2, расширения Chrome и флаги движка с Windows сюда не переносятся.

## Что есть

- **Вкладки.** Новая вкладка встаёт за той, из которой открыта; список вкладок с перетаскиванием и закрытием свайпом. Фоновая вкладка через 5 минут (настраивается, 0 — никогда) отдаёт память и загружается снова при открытии, история назад/вперёд остаётся; вкладки со звуком не выгружаются. При нехватке памяти выгружаются все фоновые. Открытые вкладки помнятся между запусками. Закрытие последней вкладки открывает плитки.
- **Плитки проектов.** Адрес проекта и до 20 ссылок, цвет, «Открыть всё» (проект в этой вкладке, ссылки в фоновых). Долгое нажатие — меню. Плитка со ссылками — папка: нажатие открывает её страницы с картинками, какими страница была, когда с неё ушли (снимок при сохранении, переходе на другую вкладку и сворачивании приложения). «Сохранить все в папку» в списке вкладок — одна плитка «Вкладки <дата>». Программы проектов на iOS не запускаются.
- **Только localhost.** Открываются только этот iPhone, локальная сеть (`192.168.*`, `10.*`, `172.16–31.*`, `*.local`, `*.localhost`) и разрешённые сайты (`x.com`, `*.y.com`). Блокирует сам движок правилами содержимого: веб-сокеты, воркеры и фреймы тоже. Включается сразу, без перезапуска. Удобно для разработки на компьютере в той же сети: `http://192.168.1.10:3000`.
- **Блокировщик рекламы и телеметрии** (включён по умолчанию). Полные списки EasyList, RU AdList и EasyPrivacy качаются при первом запуске (дальше раз в 4 дня) и переводятся в правила движка прямо на телефоне — около 130 тысяч правил, частями по 45 тысяч; движок хранит их скомпилированными, памяти почти не тратит. Пока списков нет, работает встроенный короткий список. Из синтаксиса Adblock Plus берётся то, что движок умеет точно: адреса с типами, third-party и доменами, исключения `@@`, скрытие элементов простыми селекторами; скриптлеты, `:has-text` и регулярные выражения пропускаются. На YouTube реклама проматывается, кнопка «Пропустить» нажимается сама. «Не блокировать рекламу на этом сайте» — в меню «…».
- **Защита от вредных сайтов** (включена по умолчанию): списки uBlock Badware, URLhaus и Phishing Army и Safe Browsing движка (проверка по хешам адресов через Apple). Сайт из списка не открывается: страница «Опасный сайт», «Назад» или «Всё равно открыть».
- **Пароли и способы оплаты.** Связка ключей этого устройства (без iCloud), у каждой записи доступ только после Face ID / Touch ID или код-пароля — это требование самой связки ключей, Secure Enclave. При входе на сайт — «Сохранить пароль?», на странице входа — «Войти как …», на странице оплаты — «Заполнить карту». Код CVC не хранится. Скрипт форм работает в отдельном мире JavaScript: страница его не видит и не может вызвать подстановку; пароль подставляется только во фрейм того же сайта и только по https (или в локальной сети). Кнопка «Пароли» над клавиатурой — пароли iCloud от iOS, их тоже можно выбрать. Списки и удаление — «Настройки».
- **Браузер по умолчанию.** «Настройки → Сделать браузером по умолчанию» открывает настройки iOS: «Приложение браузера по умолчанию» → LiteBro. Право на это (`com.apple.developer.web-browser`) Apple даёт только браузерам, TrollStore его сохраняет. Только в `LiteBro-Browser.tipa`: с правом `no-sandbox` (`LiteBro.tipa`, доступ ПК ко всему телефону) TrollStore ставит приложение как System, его нет в «Настройках», а «Switch to User» ломает запуск. Обе сборки — в одном `LiteBro-iOS.zip`, меняются установкой поверх; право задаётся подписью, переключателем в приложении его не сменить.
- **Звёздочка** слева в адресной строке — «Новая плитка» или «Добавить в папку» (папка — плитка, страница становится её ссылкой; повторно — убрать), золотая, если адрес уже сохранён. **Страна поиска** — в настройках и в меню «…» на странице результатов Google: параметры `gl`/`hl`, как на Windows. **Найти на странице**, **Перевести страницу** (переводчик Google через его прокси translate.goog, тот же, что в Chrome; страницы за входом и локальные он не видит) и **Открыть в Chrome**, если Chrome установлен, — в меню «…». Пока открыта клавиатура, нижняя панель спрятана.
- **Консоль страницы** (меню «…»): `console.*`, ошибки и отклонённые промисы, запросы fetch/XHR и незагрузившиеся файлы; фильтры «Ошибки», «Предупреждения», «Сеть»; строка JavaScript выполняется в странице (выражение с `await`, иначе как инструкции), CSP страницы на неё не действует. Без переключателя «Консоль с начала загрузки страницы» (Настройки → «Для разработчика», по умолчанию выключен) скрипт ставится только при открытии консоли.
- **Терминал ПК** (кнопка на стартовой странице и меню «…»): командная строка компьютера по SSH (SwiftNIO SSH + SwiftTerm). Проще всего: компьютер с LiteBro в той же Wi-Fi сам появляется в разделе «В этой сети» — «Подключить», на компьютере «Да» (тот же код из 4 цифр), и он сам включает вход по SSH (если выключен — с правами администратора) и добавляет ключ телефона; пароль Windows и QR-код не нужны. Иначе — на компьютере в LiteBro для Windows: стартовая страница → «С телефона» → «Терминал» → «Включить вход по SSH» (встроенный OpenSSH Server, порт только для частных сетей), затем QR-код камерой iPhone: ссылка `litebro://ssh?host=…&user=…&fp=SHA256:…` добавляет компьютер с ключом хоста, подменённый компьютер не пустит. Пароль Windows и ключ телефона (ed25519, «Входить по ключу с Face ID» дописывает его в `authorized_keys` или `administrators_authorized_keys`) — в связке ключей за Face ID. Пункт «Запустить Claude Code» печатает `claude`.
- **Доступ с ПК** (меню «…»): после Face ID и на выбранное время. Файлы — WebDAV и страница на `http://<телефон>:8080/<секрет>/` (`FileShare.swift`, `Shared/MiniHTTP.swift`): в Проводнике «Подключить сетевой диск» или в браузере (загрузка, новая папка, удаление, Range для видео); в `LiteBro.tipa` (право `no-sandbox`) — `/var/mobile`, в `LiteBro-Browser.tipa` — папка LiteBro; «Только чтение». Экран — расширение записи экрана (`Screen/`, ReplayKit, `LiteBroScreen.appex`): JPEG ~8 кадров/с, до 1280 px, поток `multipart/x-mixed-replace` на порту 8081, секрет и срок — в App Group от приложения. Управление касаниями (экспериментально, `Screen/Touch.swift`): мышь на странице показа — палец, кнопки «Домой» и боковая; `IOHIDEvent` через `dlsym` из расширения с правами `com.apple.private.hid.client.*` (`Screen.entitlements`), включается отдельной галочкой вместе с показом; не проверено.
- **Плитки Claude и ChatGPT** добавляются один раз; браузер представляется как Safari (`applicationNameForUserAgent`), иначе часть сайтов считает его встроенным окном приложения.
- **Загрузчик видео** (кнопка со стрелкой, красный счётчик — сколько найдено на странице):
  - в список попадает только то, что действительно загрузилось (заблокированная реклама — нет); сверху «Сейчас играет», дальше по длительности; короткие (до 45 с или до 1,5 МБ) — свёрнуты как вероятная реклама; варианты одного потока HLS спрятаны за главным плейлистом, у него — длительность и «до 1080p»;
  - файлы `mp4`, `webm`, `mov`, `mp3`, `m4a`… — из `<video>`, `<source>`, fetch/XHR и списка загруженных ресурсов страницы, с её cookies; один файл на путь (без учёта параметров);
  - потоки **HLS** (`m3u8`) — `AVAssetDownloadURLSession` берёт лучшее качество (сегменты, ключи AES-128, отдельная звуковая дорожка) и собирает в `mp4` без перекодирования; не собралось — остаётся `.movpkg`, его играет встроенный плеер;
  - **YouTube** — ссылки берутся у YouTube тем же способом, что у yt-dlp (клиент приложения YouTube для iPhone): HLS в лучшем качестве со звуком, `mp4` 360p одним файлом и звук `m4a`. Когда YouTube меняет защиту, это ломается до обновления констант в `YouTube.swift`;
  - нельзя: видео с DRM (Netflix, Apple TV+, Spotify и т. п.).
  - Скачанное — в «Загрузках» (смотреть, поделиться, «Сохранить в Фото») и в приложении «Файлы»: *На iPhone › LiteBro › Downloads*. Видео mp4 и mov сами копируются в «Фото» (переключатель в «Загрузках», по умолчанию включён). Красное число на «…» — загрузки, которые идут или готовы и ещё не открыты; в меню у «Загрузок» — подпись.
- Тёмная тема по умолчанию, светлая или как в системе; поиск Google или DuckDuckGo; русский и английский по языку системы; звук видео играет и при заблокированном экране, картинка в картинке.

## Чего нет и почему

Терминал, консоль и запуск программ проектов, журнал сети со стеками, заглушки, игнорирование CORS, эмуляция устройств, хранилище сайта, uBlock Origin Lite: на iOS нет процессов-потомков, а `WKWebView` не даёт ни перехвата всех запросов, ни DevTools-протокола, ни расширений. Отладка страниц — Safari на Mac (*Разработка › iPhone*), браузер это разрешает.

## Установка через TrollStore

TrollStore работает на iOS 14.0 – 16.6.1, 16.7 RC (20H18) и 17.0. На 16.7.x (кроме RC) и новее — нет.

1. Скачайте `LiteBro-iOS.zip` (внутри: `LiteBro.tipa` — ПК видит весь телефон, `LiteBro-Browser.tipa` — можно сделать браузером по умолчанию): страница **Releases** репозитория, выпуск «LiteBro для iOS (TrollStore)», или вкладка **Actions** → запуск «iOS» → файл `LiteBro-iOS`. Внутри — `LiteBro.tipa`: распакуйте его в «Файлах» (нажать на архив).
2. На iPhone откройте файл: «Поделиться» → **TrollStore** → Install. Или в TrollStore «+» → Install IPA File.
3. Обновление — так же, поверх: данные (плитки, вкладки, загрузки, входы на сайты) остаются.

## Отладка

- Журнал запуска: `Файлы › На iPhone › LiteBro › Debug › log.txt` (у `LiteBro.tipa` ещё копия в `/var/mobile/Media/LiteBro-Debug/`, её видят Filza и ПК). Каждый шаг запуска — со временем и памятью; падения (сигналы и исключения Objective-C) — со стеком, ещё и в `crash.txt`. Пишется сразу в файл, поэтому остаётся, даже если система убила приложение. В приложении — «Настройки › Отладка › Журнал отладки» (отправить, копировать, очистить).
- Безопасный режим: если прошлый запуск не дошёл до конца (5 с после первого экрана), LiteBro открывается без сохранённых вкладок, списков фильтров и правил блокировки, на стартовой странице — оранжевая плашка с последним шагом. Работа, во время которой приложение умерло (`build-lists`, `malware-lists`, `rules`), пропускается и дальше, пока не нажать «Обновить списки». Безопасный режим можно заказать и вручную в настройках.

## Сборка

Собирать нужно на Mac, поэтому собирает GitHub Actions (`.github/workflows/ios.yml`, раннер macOS) при каждом изменении `ios/`. Локально на Mac:

```sh
brew install xcodegen ldid
cd ios
xcodegen generate                 # LiteBro.xcodeproj из project.yml
open LiteBro.xcodeproj            # обычный запуск на симуляторе или телефоне с вашей командой
```

`.tipa` вручную — команды шагов «Build» и «Pack .tipa» из workflow. Загрузка HLS (`AVAssetDownloadTask`) на симуляторе не работает, только на устройстве.

## Код

- `App/` — вход и настройки (`Prefs`, `L()` — перевод: ключ — русский текст, английский в `Resources/en.lproj/Localizable.strings`).
- `Browser/` — `Browser` (вкладки, общий `WKUserContentController`, правила, сессия), `BrowserTab` (WKWebView вкладки, навигация, выгрузка, разбор найденного видео, `HLS`), `LocalNet` (только localhost), `AdBlock` (встроенный список, перемотка рекламы YouTube, `RuleStore` — компиляция и кэш списков), `FilterLists` (загрузка списков, перевод Adblock Plus → правила WebKit, вредные сайты), `Vault` (пароли и карты, `VaultScript`), `Translate`, `MediaSniffer` (скрипт поиска видео), `TileStore`.
- `Downloads/` — `DownloadManager` (файлы, HLS → mp4, загрузки страниц), `YouTube`, `MediaItem`.
- `Views/` — SwiftUI.
